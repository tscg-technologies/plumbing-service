## 4. Instructions for Replacing Placeholders with Generated Images

When real photographs are generated using Google Flow or other image tools:
1. Generate the images at the recommended resolutions noted in the table above.
2. Save or convert images to the modern `.webp` format (or `.jpg`/`.png` if preferred) using the **exact filenames** specified in the inventory table.
3. Place all generated image files into the website root directory:
   ```text
   p:\TSCG\2027 Demo Websites\Plumbing Service\
   ```
4. In each HTML file, simply replace the placeholder markup:
   ```html
   <!-- Replace this placeholder block: -->
   <div class="img-placeholder ratio-4-3" role="img" aria-label="Kitchen Sink Pipe Inspection">
     ...
   </div>

   <!-- With the standard responsive image tag: -->
   <img src="plumbing-service-hero.webp" 
        alt="Professional plumber inspecting water pipes under kitchen sink" 
        class="img-fluid" 
        loading="lazy" 
        width="1200" 
        height="900">
   ```
5. All layout containers already possess fixed aspect ratios and responsive constraints, ensuring zero Cumulative Layout Shift (CLS) when real images are placed into the markup.
